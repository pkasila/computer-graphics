# Лабораторная работа №2 — Обработка изображений

## Описание

В этой лабораторной работе реализованы базовые методы обработки изображений на чистом JavaScript/TypeScript с использованием HTML5 Canvas. Вся логика реализована без внешних библиотек, что обеспечивает стабильность и прозрачность работы.

## Основные функции

- Генерация тестовых изображений: шумное, размазанное, низкоконтрастный градиент, полосатая текстура.
- Загрузка пользовательских изображений через `<input type="file">`.
- Визуализация: исходное и обработанное изображение, гистограммы яркости.
- Медианный фильтр: подавление шума, регулируемый радиус.
- Линейное растяжение контраста: ручная настройка диапазона.
- Гистограммное выравнивание: по каналам RGB и по яркости (HLS).
- Сброс и скачивание результата.

## UI/UX

- Современный необрюталистский интерфейс, адаптивная верстка.
- Все элементы управления реализованы с помощью стандартных HTML-элементов и кастомных стилей (`src/style.css`).

## Технические детали

- Вся обработка изображений реализована вручную через Canvas API.
- Алгоритмы фильтрации и коррекции реализованы асинхронно для плавной работы UI.
- Гистограммы строятся по яркости (Rec.601 luma).
- Код структурирован для легкой поддержки и расширения.
