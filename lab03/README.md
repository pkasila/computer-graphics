### Привязка координат к сетке

- Каждая точка соответствует центру клетки дискретной сетки.
- Координаты отображаются при наведении мыши.
- Масштаб сетки регулируется слайдером.
- Оси, сетка и подписи реализованы для удобства.

### Пример вычислений

Для построения линии:
- dx, dy — разности координат
- steps — количество шагов
- xInc, yInc — приращения
- На каждом шаге вычисляется новая координата и закрашивается пиксель
