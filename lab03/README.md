## Краткий отчёт

Реализованы и протестированы алгоритмы:
- Пошаговый: Наивный алгоритм, основанный на уравнении прямой $y=kx+b$
- ЦДА: Цифровой дифференциальный анализатор. Инкрементальный алгоритм с использованием вещественной арифметики.
- Брезенхем (линия): Оптимизированный алгоритм, использующий только целочисленную арифметику и анализ ошибки.
- Брезенхем (окружность): Генерация окружности с использованием 8-кратной симметрии.
- Ву (сглаживание): Генерация линий с устранением ступенчатого эффекта (aliasing) через управление прозрачностью.

## Описание принципа работы алгоритмов

**Пошаговый:**
Наивный алгоритм построения линии по уравнению $y = kx + b$. На каждом шаге вычисляется новая координата, округляется до ближайшего целого, и закрашивается соответствующий пиксель. Простой, но может давать ступенчатые линии и артефакты при больших углах.

**ЦДА:**
Инкрементальный алгоритм, использующий вещественную арифметику. На каждом шаге к координатам прибавляется приращение $xInc$ и $yInc$, что обеспечивает равномерное распределение пикселей. Линия получается более ровной, чем у пошагового, но возможны накопления ошибок округления.

**Брезенхем (линия):**
Оптимизированный целочисленный алгоритм. Использует анализ ошибки для выбора пикселя, не требует вещественных вычислений. Линии получаются ровными, без пропусков и с минимальными артефактами. Хорошо подходит для графических приложений.

**Брезенхем (окружность):**
Построение окружности с использованием 8-кратной симметрии. На каждом шаге вычисляются координаты для всех восьми октантов, что ускоряет построение и обеспечивает симметрию.

**Ву:**
Алгоритм сглаживания линии. Для устранения aliasing (ступенчатости) закрашиваются соседние пиксели с разной прозрачностью, что визуально делает линию более плавной. Требует дополнительных вычислений и работы с альфа-каналом.

## Влияние параметров "Масштаб" и "Задержка"

- **Задержка шага алгоритма (latency):** Позволяет наблюдать пошаговое выполнение алгоритма. На итоговое качество не влияет, но увеличивает время построения. При изменении масштаба задержка игнорируется для быстрой перерисовки.
- **Масштаб (zoom):** Позволяет детально рассмотреть работу алгоритма. При увеличении масштаба видны особенности построения, ступенчатость, сглаживание. Все построенные объекты сохраняются и перерисовываются при изменении масштаба.

## Практические рекомендации

- Для построения прямых используйте Брезенхем (линия) — оптимален по скорости и качеству.
- Для окружностей — Брезенхем (окружность), особенно если важна симметрия.
- Для визуализации сглаженных линий — Ву, если не критична скорость.
- Пошаговый и ЦДА подходят для простых задач и обучения, но не рекомендуются для финальных графических приложений.
- Используйте задержку для демонстрации работы алгоритма, но отключайте для массовых построений.
- Экспортируйте холст для отчётов и анализа.
- Масштабируйте сетку для анализа точности и особенностей построения.

## Привязка целочисленных координат к дискретной сетке

В данной работе каждая точка, которую закрашивает алгоритм, соответствует центру клетки дискретной сетки. Координаты (X, Y) — это логические значения, которые преобразуются в экранные пиксели с учётом масштаба и положения центра. Формула пересчёта:

- **`screenX = centerX + X * gridSize`**
- **`screenY = centerY - Y * gridSize`**

Таким образом, логические координаты всегда попадают в центр соответствующей клетки, а изменение масштаба позволяет детально рассмотреть расположение и форму построенных объектов. Это обеспечивает корректную визуализацию и точное соответствие математической модели дискретной сетке.
