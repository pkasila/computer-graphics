# Лабораторная работа №3 — Базовые растровые алгоритмы

## Краткий отчет

Реализованы и протестированы алгоритмы:
- Пошаговый (Step): Наивный алгоритм, основанный на уравнении прямой $y=kx+b$
- ЦДА (DDA): Цифровой дифференциальный анализатор. Инкрементальный алгоритм с использованием вещественной арифметики.
- Брезенхем (линия): Оптимизированный алгоритм, использующий только целочисленную арифметику и анализ ошибки.
- Брезенхем (окружность): Генерация окружности с использованием 8-кратной симметрии.
- Ву (сглаживание): Генерация линий с устранением ступенчатого эффекта (aliasing) через управление прозрачностью.

### Временные характеристики и количество закрашенных пикселей

| Алгоритм           | Время выполнения (мс) | Закрашено пикселей |
|--------------------|----------------------|--------------------|
| Step               | 571.000              | 11                 |
| DDA                | 567.000              | 11                 |
| Bresenham Line     | 581.000              | 11                 |
| Bresenham Circle   | 409.000              | 64                 |
| Wu                 | 1239.000             | 22                 |

### Сравнение алгоритмов

- **Step, DDA, Bresenham Line** — дают одинаковое количество пикселей для прямой, но Bresenham работает чуть медленнее из-за дополнительной логики.
- **Bresenham Circle** — существенно отличается по количеству пикселей, так как строит окружность.
- **Wu** — самый медленный, но обеспечивает сглаживание (больше пикселей, плавные края).

### Выводы по работе алгоритмов

- Все алгоритмы корректно реализованы и протестированы.
- Step и DDA просты, но менее оптимальны по сравнению с Bresenham.
- Bresenham Line — оптимальный для построения прямых, использует только целые числа.
- Bresenham Circle — эффективен для окружностей, использует симметрию.
- Wu — обеспечивает сглаживание, но требует больше времени и ресурсов.
