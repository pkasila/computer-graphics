# Лабораторная работа №3 — Базовые растровые алгоритмы

## Краткий отчет

Реализованы и протестированы алгоритмы:
- Пошаговый (Step): Наивный алгоритм, основанный на уравнении прямой $y=kx+b$
- ЦДА (DDA): Цифровой дифференциальный анализатор. Инкрементальный алгоритм с использованием вещественной арифметики.
- Брезенхем (линия): Оптимизированный алгоритм, использующий только целочисленную арифметику и анализ ошибки.
- Брезенхем (окружность): Генерация окружности с использованием 8-кратной симметрии.
- Ву (сглаживание): Генерация линий с устранением ступенчатого эффекта (aliasing) через управление прозрачностью.

### Привязка координат к сетке

- Каждая точка соответствует центру клетки дискретной сетки.
- Координаты отображаются при наведении мыши.
- Масштаб сетки регулируется слайдером.
- Оси, сетка и подписи реализованы для удобства.

### Пример вычислений

Для построения линии:
- dx, dy — разности координат
- steps — количество шагов
- xInc, yInc — приращения
- На каждом шаге вычисляется новая координата и закрашивается пиксель
