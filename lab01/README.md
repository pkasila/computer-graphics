# Лабораторная работа №1 — Цветовые модели: RGB, HLS, CMYK

## Описание

В этой лабораторной работе реализовано интерактивное преобразование и сравнение цветовых моделей RGB, HLS и CMYK на чистом JavaScript/TypeScript. Вся логика реализована вручную, без сторонних библиотек, с использованием HTML5 и Canvas API.

## Основные функции

- Выбор цвета через цветовой селектор (`<input type="color">`) или ручной ввод HEX.
- Мгновенное отображение выбранного цвета и его HEX-кода.
- Автоматическое преобразование между моделями RGB, HLS и CMYK.
- Редактирование компонентов каждой модели с помощью текстовых полей и слайдеров.
- Копирование HEX-кода цвета в буфер обмена.
- Сброс к чёрному цвету (по умолчанию).
- Сохранение выбранного цвета между сессиями (localStorage).

## UI/UX

- Современный необрюталистский интерфейс, адаптивная верстка.
- Все элементы управления реализованы с помощью стандартных HTML-элементов и кастомных стилей (`src/style.css`).

## Технические детали

- Все преобразования между моделями реализованы вручную (см. `src/colors.ts`).
- Значения компонентов ограничены и валидируются для корректного ввода.
- Код структурирован для легкой поддержки и расширения.
- Toast-уведомления при копировании HEX-кода.
