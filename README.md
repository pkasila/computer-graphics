# Компьютерная графика — лабораторные работы

[![Deploy Vite Apps to GitHub Pages](https://github.com/pkasila/computer-graphics/actions/workflows/workflow.yml/badge.svg)](https://github.com/pkasila/computer-graphics/actions/workflows/workflow.yml)

## Описание репозитория

В этом репозитории собраны лабораторные работы по курсу "Компьютерная графика". Каждая лабораторная реализована как отдельный проект с современным интерфейсом, чистым TypeScript/JavaScript и адаптивной версткой. Все работы запускаются локально через Vite и не требуют сторонних зависимостей для обработки изображений.

### Структура
- `lab01/` — Цветовые модели (RGB, HLS, CMYK)
- `lab02/` — Базовые методы обработки изображений
- `lab03/` — Алгоритмы растеризации (линии, окружности и др.)
- `index.html` — Главная страница с навигацией по лабораторным

## Как собрать и запустить

1. Клонируйте репозиторий:
   ```zsh
   git clone https://github.com/pkasila/computer-graphics.git
   cd computer-graphics
   ```
2. Для каждой лабораторной перейдите в соответствующую папку и установите зависимости:
   ```zsh
   cd lab01 # или lab02, lab03
   npm install
   ```
3. Запустите локальный сервер:
   ```zsh
   npm run dev
   ```
4. Откройте в браузере адрес, указанный в терминале (обычно `http://localhost:5173`).

## Размещение и деплой

Для создания сборки для размещения используйте команду:
```zsh
npm run build
```
После сборки статические файлы будут находиться в папке `dist/`.
